Statistical Summary

What these readings mean

Total Images
How many labeled test images were included in the evaluation.
Overall Accuracy
The percentage of all uploaded test images that the model classified correctly.
Macro F1
The average F1 score across classes where every class counts equally.
Weighted F1
The F1 score averaged by class size, so classes with more test images have more influence.
Balanced Accuracy
The average recall across classes, useful when the test set is not evenly balanced.
Calibration Error
How far the model's confidence is from its actual correctness. Lower is better.

Per-Class Performance

Class Support Predicted Precision Recall Recall 95% CI Specificity F1

What each column means

Class
The banana disease or healthy category being evaluated.
Support
Number of test images uploaded with this class as the true label.
Predicted
Number of images the model predicted as this class, regardless of the true label.
Precision
When the model predicted this class, how often it was correct.
Recall
Out of all images truly belonging to this class, how many the model detected.
Recall 95% CI
The uncertainty range for recall. Wider intervals usually mean fewer test images.
Specificity
How well the model avoids falsely labeling other classes as this class.
F1
A combined score balancing precision and recall.

Macro treats every class equally; weighted gives larger classes more influence.

Average ability to avoid false alarms for each class.

Healthy Vs Diseased Screening

Accuracy Sensitivity Specificity Precision FPR FNR F1 ROC-AUC PR-AUC Brier

What each column means

Accuracy
Overall correctness when reducing the model to Healthy versus Diseased.
Sensitivity
How many truly diseased leaves were detected as diseased. Also called recall.
Specificity
How many truly healthy leaves were correctly kept as healthy.
Precision
When the model says diseased, how often it is actually diseased.
FPR
False positive rate: healthy leaves incorrectly flagged as diseased.
FNR
False negative rate: diseased leaves incorrectly missed as healthy.
F1
Balance between diseased precision and diseased sensitivity.
ROC-AUC
How well the model separates healthy from diseased across thresholds. Higher is better.
PR-AUC
Precision-recall area for diseased detection, useful when healthy and diseased counts are imbalanced.
Brier
Probability error for Healthy versus Diseased confidence. Lower is better.

Confidence Bin Count Accuracy Avg Confidence Gap

What each column means

Confidence Bin
The prediction confidence range, such as 0.7 to 0.8.

Number of predictions that landed in that confidence range.

How many predictions in the bin were actually correct.

The average confidence score for predictions in the bin.
Gap
The difference between accuracy and confidence. Smaller gaps mean better calibrated confidence.

Confidence Thresholds

Threshold Accepted Rejected Coverage Accepted Accuracy Accepted Errors

What each column means

Threshold
The minimum confidence required before accepting a prediction.
Accepted
Number of predictions at or above that threshold.
Rejected
Number of predictions below that threshold that would need review.
Coverage
Percentage of all predictions that would be accepted automatically.
Accepted Accuracy
Accuracy among only the accepted predictions.
Accepted Errors
Number of wrong predictions that would still pass the threshold.
